# Изменения

Сверху — новые. Номер версии совпадает с тегом релиза и тегом образа. Раздел версии попадает на
страницу релиза в «Что нового».

## 1.3.0 — 2026-10-20

- **Рассылка на телефоне:** «⋯» у подписки открывает лист снизу со всеми действиями — отправить,
  изменить, включить или отключить, удалить. На компьютере у подписки появилась кнопка
  «Отключить» / «Включить».
- Меню действий больше не обрезается краем таблицы — ни у подписок, ни у пользователей.
- Сервис пишет свою версию в журнал при старте (`sender_starting`), образ собирается с номером
  версии из тега.
- Зависимости: EF Core и ASP.NET Core 10.0.13, MailKit 4.18.1, Testcontainers 4.16, сборка панели
  на Node 24, действия GitHub Actions — текущие версии.
- Порядок в коде: стили панели разложены по разделам, убраны неиспользуемые части и устаревшие
  комментарии, лишние `using` теперь останавливают сборку.

## 1.2.0 — 2026-10-20

- «Сертификаты» показывают только то, что пришло в последнем опросе Key Manager Plus; пропавшие
  забываются через 30 дней.
- «Безопасность» — настройки по категориям и одна кнопка «Сохранить».
- Архив для Portainer: `docker-compose.yml`, `.env.example`, образ и инструкция. Служба `migrate`
  выполняется при каждом развёртывании; первый администратор и сброс доступа задаются
  переменными стека.

## 1.1.0 — 2026-10-20

- Вкладки «Сертификаты» (скачать файл, показать закрытый ключ), «Настройки» (почта, Key Manager)
  и «Безопасность».
- Скачивание сертификатов и ключей, изменения настроек, людей и подписок подтверждаются кодом из
  приложения; код действует 10 минут (`auth.step_up_minutes`).
- Режим телефона: раскладка выбирается режимом браузера, а не шириной экрана.
- Команда `reset-access`: новый пароль, снятие второго фактора, блокировки и сессий — одной
  транзакцией.
- Неактивированное приглашение больше не позволяет последнему администратору удалить или
  отключить себя. Панель отправляет только изменённые настройки.

## 1.0.2 — 2026-10-20

- Сервис ходит в базу отдельной ролью `sender_app` без прав суперпользователя и без права
  менять схему.

## 1.0.1 — 2026-10-20

- Вход: без аутентификатора сессию нельзя подтвердить кодом из письма.

## 1.0.0 — 2026-10-20

- Первый выпуск: рассылка SSL-сертификатов из Key Manager Plus по подпискам, учётные записи со
  вторым фактором, почта по SMTP, веб-панель, Docker Compose и Cloudflare Tunnel.
